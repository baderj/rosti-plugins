# Rösti plugins

Claude plugin marketplace for [Rösti](https://rosti.dev) threat intelligence.

| Plugin | What it does |
| --- | --- |
| [`rosti`](plugins/rosti) | Check IOCs, research CVEs, read reports and export indicators |

```
claude plugin marketplace add baderj/rosti-plugins
claude plugin install rosti@rosti-plugins
```
